# FPGA Object Detection using CNN Accelerator on ZedBoard

This repository is a complete implementation guide for building a CNN accelerator on a Xilinx ZedBoard using Vivado 2025.2 and PetaLinux 2025.2.

The project starts from a blank Ubuntu installation and ends with real-time hardware-accelerated object detection.

---

# Who is this repository for?

- Students learning FPGA acceleration
- Beginners working with Zynq SoCs
- Researchers implementing CNNs on FPGA
- Anyone wanting a step-by-step implementation

---

# Prerequisites

- Ubuntu
- Vivado 2025.2
- PetaLinux 2025.2
- ZedBoard
- SD Card
